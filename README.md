# PawfectHome

PawfectHome adalah situs statis bertema adopsi hewan. Situs ini menampilkan hewan yang menunggu rumah baru, langkah-langkah adopsi, testimoni, dan informasi tentang misi PawfectHome.

## Menjalankan

Tidak perlu instalasi atau dependensi tambahan. Buka `index.html` langsung di browser.

## Struktur Proyek

- `index.html` berisi struktur dan konten halaman.
- `Assets/style.css` berisi tampilan dan layout situs.
- `script.js` mengatur menu mobile, navigasi aktif, carousel hewan, dan testimoni.
- `Assets/Images/` menyimpan gambar yang digunakan di halaman.
